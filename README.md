# Customer Churn Analysis Dashboard

An interactive customer churn analytics dashboard built with **Python, SQL, scikit-learn, Plotly, and Streamlit**.

The application joins customer and billing data from SQLite, analyzes churn patterns across customer segments, and uses a Random Forest classifier to identify customers with the highest predicted churn risk.

## Dashboard highlights

- High-level business metrics: total customers, churn rate, average monthly charge among churned customers, and estimated annual revenue at risk
- Interactive filters for contract type and internet service
- Churn-rate comparisons by contract and internet service
- Ranked table of the highest-risk customers
- Customer-level churn probability generated by a Random Forest model
- ROC-AUC score displayed directly in the dashboard for model evaluation

## Tech stack

- **Python** - application and data-processing language
- **Streamlit** - interactive dashboard interface
- **SQLite** - local relational data storage
- **Pandas** - data loading and transformation
- **Plotly Express** - interactive visualizations
- **scikit-learn** - model training and evaluation
- **Jupyter Notebook** - exploratory analysis in `churn_analysis.ipynb`

## How it works

1. `app.py` loads customer and billing records from `churn.db` using a SQL join.
2. Categorical variables are converted into model-ready features with one-hot encoding.
3. The data is split into training and test sets using stratified sampling.
4. A Random Forest classifier estimates the probability that each customer will churn.
5. Streamlit presents the business metrics, visual analysis, filters, and high-risk customer table in one dashboard.

## Getting started

### Prerequisites

- Python 3.9 or later
- `pip`

### Installation

Clone the repository and move into the project directory:

```bash
git clone https://github.com/shabaj003/churn-analysis.git
cd churn-analysis
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run the dashboard

```bash
streamlit run app.py
```

Streamlit will provide a local URL, typically `http://localhost:8501`.

## Data

The included SQLite database contains two related tables:

- `customers` - demographic, service, contract, and payment information
- `billing` - tenure, monthly charges, total charges, and the churn label

The tables are joined using `customerID`. The included dataset contains 7,043 customers.

## Model details

The dashboard trains a `RandomForestClassifier` with:

- 200 estimators
- Maximum tree depth of 10
- An 80/20 stratified train-test split
- ROC-AUC used as the evaluation metric

The resulting probability is shown as `churn_risk_score` and is used to rank customers in the at-risk table.

## Notebook

Use `churn_analysis.ipynb` for exploratory analysis and to investigate the dataset before launching the dashboard.
